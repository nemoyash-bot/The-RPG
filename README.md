# ⚔️ The RPG

A Python RPG that I (an 11 yr old) am building from scratch!

## 🎮 About the Game

**The RPG** is a turn-based adventure game where you explore dangerous forests, fight enemies, collect gold, buy equipment, complete quests, and become stronger.

The game is being developed in Python.
